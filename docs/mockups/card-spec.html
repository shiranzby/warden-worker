卡片规范统一 · 前后对比

对象：Open Design 交付的设计系统 pages/_shared/app.css。 问题不是"审美"，而是同一层级的容器用了不同的内边距与圆角，并排时肉眼可见不齐。 下面是逐项对照与可直接并入 app.css 的补丁。

① 现在的问题：8 个"像卡片"的类，是 3 套内边距 × 3 种圆角

✕ 修正前（现状）
主卡片 .card20px / r18 / #fff
报告卡 .report-card18px / r18 / #fff
统计块 .stat14/16px / r12 / warm
备注块 .notes  → 14/16px / r12 / surface
选项卡 .opt-card → 12/14px / r12 / #fff
生成结果 .gen-out → 12px / r12 / surface
拖放区 .dropzone → 26/18px / r12
提示条 .banner → 6/8/10px / r8（还是第三档圆角）

最刺眼的是 .card(20px) 与 .report-card(18px) —— 两个都是**顶层主卡片**，并排时上下留白差 2px；而 .stat 与 .notes 同为内嵌块，却一个用 --surface-warm 一个用 --surface。

✓ 修正后（两档 + 一个明确的例外）
主卡片20px / r18 / #fff
主卡片（原 report-card 归此档）20px / r18 / #fff
内嵌块 · 统计 .stat  → 14/16px / r12 / surface
内嵌块 · 备注 .notes → 14/16px / r12 / surface
内嵌块 · 选项卡 .opt-card → 14/16px / r12 / surface
内嵌块 · 生成结果 .gen-out → 14/16px / r12 / surface
拖放区 .dropzone → 22/18px / r12 / surface（虚线保留）
行内提示条 .banner → 8/12px / r8（明确不是卡片）

规则只有三条：主卡片统一 A 档、内嵌块统一 B 档、 提示条不算卡片但取值固定。层级感靠"白 vs 浅灰"表达，不再靠 padding 差 2px。

② 规范表

档包含的类padding圆角背景边框
A · 主卡片 .card .report-card .panel .login-card .lock-card var(--space-5) = 20px--radius-lg = 18px --bg1px --border
B · 内嵌块 .notes .stat .gen-out .opt-card 14px 16px--radius-md = 12px --surface1px --border
B′ · 拖放区 .dropzone 22px 18px--radius-md = 12px --surface1px dashed --border
N · 行内提示条 .banner（不属于卡片） 8px 12px--radius-sm = 8px --accent-soft无

另：把 --surface-warm 从"内嵌块背景"里撤出 —— 它和 --surface 只差 4 个色阶（#fbfbfd vs #f5f5f7），肉眼分不出却被当成两套，是"看着乱"的另一半来源。 建议只保留一个内嵌块灰，--surface-warm 留给页面级的极浅分区。

③ 可直接并入 app.css 的补丁

/* ===== 卡片规范统一（追加到 app.css 末尾即可；本文件在最后，天然覆盖前面的同权重声明） ===== */

/* A 档 · 主卡片：内边距与圆角只认这一组值 */
.card, .report-card, .panel, .login-card, .lock-card {
  padding: var(--space-5);
  border-radius: var(--radius-lg);
  background: var(--bg);
  border: 1px solid var(--border);
}

/* B 档 · 内嵌块：比主卡片小一号，但四个类之间必须一致 */
.notes, .stat, .gen-out, .opt-card {
  padding: 14px 16px;
  border-radius: var(--radius-md);
  background: var(--surface);
  border: 1px solid var(--border);
}

/* B′ · 拖放区：虚线边框是语义，保留；尺寸归到 B 档的大变体 */
.dropzone {
  padding: 22px 18px;
  border: 1px dashed var(--border);
  border-radius: var(--radius-md);
  background: var(--surface);
}

/* N · 行内提示条：不是卡片，但取值固定下来 */
.banner {
  padding: 8px 12px;
  border-radius: var(--radius-sm);
  background: var(--accent-soft);
}

/* 危险语义只换边框色，不再另起一套尺寸 */
.danger-card { border-color: color-mix(in oklab, var(--danger) 42%, var(--border)); }

/* 卡片内的卡片：保持"层级递减"，不要继承主卡片的内边距 */
.card .card,
.card .notes,
.card .stat,
.card .gen-out { padding: 14px 16px; border-radius: var(--radius-md); }
